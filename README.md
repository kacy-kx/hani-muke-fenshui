# 木刻分水 · The Notched Ledger

哈尼梯田木刻分水制度的可计算水账本。

把「木刻分水」这套乡土水权制度落成三种可执行规则（按亩 / 按户 / 按时段轮灌），
实时算出每户水量、基尼系数、干旱缺口，并用矩形薄壁堰公式把水权份额反算成刻口宽度。

- 纯静态单页，零依赖、可离线运行
- 中英双语切换
- 在线访问：<https://kacy-kx.github.io/hani-muke-fenshui/>
